# 🌦️ Weather App

A responsive and user-friendly Weather Application built using **HTML, CSS, Bootstrap, and JavaScript**. This application fetches real-time weather data using the **OpenWeatherMap API** and provides detailed weather information for any city searched by the user.

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Current temperature display
* 🔄 Toggle between Celsius (°C) and Fahrenheit (°F)
* 💧 Humidity information
* 🌬️ Air Quality Index (AQI)
* 🌅 Sunrise and Sunset timings
* 📅 5-Day Weather Forecast
* 🎨 Dynamic background themes based on weather conditions
* 🌙 Light/Dark mode support
* 📱 Fully responsive design for desktop and mobile devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript (ES6)
* OpenWeatherMap API

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/MuthamilSellamuthu/WeatherApp.git
```

2. Navigate to the project folder:

```bash
cd WeatherApp
```

3. Open `index.html` in your browser.

## 🔑 API Configuration

1. Create an account on OpenWeatherMap.
2. Generate an API Key.
3. Replace the API key in `script.js`:

```javascript
const apiKey = "YOUR_API_KEY";
```
